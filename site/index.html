Desktop Architecture

Why GNOME 50 Beats Bare Window Managers

Tiling window managers look neat in screenshots until you plug in a second monitor, open a dialogue window, or try to scale a 4K display. Gnomarchy provides a superior balance.

🖥️

Flawless 4K Fractional Scaling

Mutter’s native Wayland pipeline handles mixed-DPI setups effortlessly. Run 125% or 150% scaling without the blurry text and scaling bugs common on standalone Wayland compositors.

🧩

Tactile Grid Over Rigid Auto-Tiling

Auto-tiling forces every popup or preview window into an awkward narrow slot. With Tactile (Super + T), your windows stay where you want them until you intentionally snap them.

🛡️

Rock-Solid GDM & Power Profiles

Reliable suspend-then-hibernate, display hot-plugging, PipeWire audio routing, and GDM lock screen integration that just work every single time you open your laptop lid.

Deployment

Install Gnomarchy

Get a complete developer desktop deployed in under two minutes.

Method 1 · Recommended

Bootable Installation ISO

Write the bootable ISO to a USB flash drive. The installer partitions Btrfs subvolumes, installs Snapper, configures Limine, and deploys GNOME 50.

Download Gnomarchy ISO
# Flash to USB (replace /dev/sdX) sudo dd if=gnomarchy-linux.iso of=/dev/sdX bs=4M status=progress
Method 2 · Quick Deploy

Deploy Over Minimal Arch

Have a clean minimal Arch Linux install? Run the automated deploy script to install all desktop components and developer tooling.

curl -fsSL https://raw.githubusercontent.com/hteariH/Gnomarchy/main/boot.sh | bash

Or test in a virtual machine first: clone the repo and execute ./run-vm.sh with QEMU.
