Linux used to be a chore to setup, difficult to debug, and full of confusing upfront choices. Gnomarchy solves all of it with a lightning fast installation, agents that debug all issues, and fantastic defaults that give you a fully functioning system that looks amazing out of the box.

Oma is for omakase, chef’s choice: the chef picks the courses, but you are always free to send anything back. Gnomarchy takes that exact spirit and brings it to GNOME: rock-solid display scaling, native Wayland polish, and tactile grid tiling.

It’s not perfect... yet. But we can fix everything now.

Install Gnomarchy

Be up and running in as little as 35 seconds on the fastest machines, and in less than two minutes on the majority of computers.

Full installation guide

Full-disk or dual-boot installation

Write the ISO to a USB stick and answer five questions. It hands back a finished GNOME desktop.

Download Gnomarchy 1.0 ISO

Under two minutes from stick to desktop. Verify the file: SHA-256, signature.

Try it first or quick script

Deploy straight over a minimal Arch base or run in a local virtual machine to get a taste first.

curl -fsSL https://raw.githubusercontent.com/hteariH/Gnomarchy/main/boot.sh | bash

Run QEMU test: ./run-vm.sh. Fast shutdown limits tuned to 10s.

A superpower for every dream, every desire

Built-in tools that make computing fun, lightning-fast, and keyboard-centric.

Tactile Grid Tiling

Hit Super + T to summon an interactive grid overlay and position windows instantly without rigid WM headaches.

Voxtype AI Dictation

Dictate text with Super + D using local, offline Whisper neural speech models. Zero fees, zero telemetry.

Web App Factory

Run gnomarchy webapp add "Claude" "https://claude.ai" to turn web apps into isolated desktop apps pinned to your left dock.

Nautilus Superpowers

Native right-click actions: compress video to 25MB for Discord, create animated GIFs, extract MP3 audio, and strip EXIF data.

Atomic Snapper Rollbacks

Automatic Btrfs snapshots before updates. If an experiment goes sideways, select an earlier snapshot directly in Limine upon reboot.

Privacy Defaults

Brave Origin pre-configured as the system default with all crypto, telemetry, and AI bloat removed. Micro as the modern CLI editor.

The agentic OS for the age of agents

Your agent should feel at home on your computer. Gnomarchy gives it the tools and skills to help you understand, fix, and shape the whole system.

Choose your agent

Claude Code, Antigravity, OpenCode, or custom scripts. Gnomarchy comes with a pre-installed AGENTS.md protocol layer ready on first boot.

Make sense of a crash

When an application misbehaves, your agent inspects coredumpctl and systemd journals to diagnose what broke and help submit patches.

Make it your own

Hook your agent into system lifecycle events in ~/.config/gnomarchy/hooks/. React automatically to theme changes, snapshots, and updates.

Pick a theme, change everything

A theme restyles the whole system at once: terminal, bar, notifications, wallpaper. Pick one and this site wears it too. Or press T to flip through them.

Developed by developers for developers

The tools you know, set up to work together. Bring your projects, choose your favorites, and get straight to building.

Your editor, integrated

Micro is configured as your modern CLI editor. Neovim, VSCode, Cursor, and Zed are ready to install with pre-aligned themes.

Your stack, ready to go

Node.js, Python, Ruby, Rust, and Docker work out of the box with optimal systemd limits and fast packaging.

GPU Terminal

Alacritty provides lightning-fast GPU-accelerated rendering. Prefer Kitty or Ghostty? All match your active theme automatically.

It even runs Windows!

Keep the Windows apps you need, right inside Gnomarchy. Our Windows 11 VM setup makes room for native Microsoft Office and programs you can't leave behind.

Your Windows apps, at home

Run gnomarchy windows start. Hardware virtualization brings near-native CPU performance with shared clipboard and host folders.

VirtIO & TPM 2.0

Pre-configured with fast VirtIO storage and software TPM 2.0 (swtpm) for effortless Windows 11 Pro compliance.

Momentum by the numbers

Clean architecture, rolling stability, and open contributions. Momentum is based on all of it.
