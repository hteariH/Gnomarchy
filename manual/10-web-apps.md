# Web Apps

Turn a website into a desktop application with its own window, icon and
profile.

```bash
gnomarchy webapp add "Linear" "https://linear.app"
gnomarchy webapp list
gnomarchy webapp remove "Linear"
```

Also under Web App in the command center.

## What you get

An isolated browser profile, a fetched favicon, and a desktop entry, so the app
shows up in the app grid and can be pinned to the dock like anything else. It
does not share cookies with your normal browsing.

## Good candidates

Anything you keep open all day and want in its own window rather than as a tab:
chat, mail, calendars, project trackers, AI assistants.
